# Alke Wallet 💳

Alke Wallet es un prototipo interactivo de billetera digital desarrollado como proyecto integrador para el bootcamp de Desarrollo Front-end.

## 🚀 Funcionalidades Principales
- **Autenticación**: Inicio de sesión simulado mediante credenciales locales.
- **Gestión de Saldo**: Consulta de saldo disponible actualizado dinámicamente en `localStorage`.
- **Depósitos y Transferencias**: Simulación de recarga de fondos y transferencias de dinero entre contactos.
- **Directorio de Contactos**: Agendar nuevos contactos y buscar nombres con soporte de autocompletado.
- **Historial de Movimientos**: Registro completo con fecha, hora y tipo de transacción (ingreso o egreso).

## 🛠️ Tecnologías Utilizadas
- **HTML5**: Estructuración semántica de páginas.
- **CSS3 & Bootstrap 5**: Maquetación responsive, interfaz moderna y componentes visuales.
- **JavaScript (ES6)**: Lógica del sistema y persistencia de datos con `localStorage`.
- **jQuery**: Animaciones del DOM, búsqueda interactiva y optimización de eventos.

## 📂 Repositorio y Ramas (Git Workflow)
- `main`: Código de producción.
- `feature/login`: Módulo de acceso e inicio de sesión.
- `feature/depositos`: Funcionalidades de depósito y cálculo de fondos.
- `feature/transacciones`: Sistema de envío a contactos e historial de datos.
